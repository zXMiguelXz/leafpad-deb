# Leafpad
Paquete .deb de leafpad, paquete creado por https://github.com/zXMiguelXz.

Todos los derechos de la aplicación son de https://github.com/tarot231.

# Instalación en entornos Debian

Hay que tener en cuenta que las dependencias de este paquete son las librerias GTK+ 2.0 hacia arriba.


```
sudo chmod +x leafpad_0.8.17le2-1_amd64.deb && sudo dpkg -i leafpad_0.8.17le2-1_amd64.deb
```
